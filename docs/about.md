# About

## What is FUM-AI-Archive?

FUM-AI-Archive is a GitHub organization created and maintained by teaching
assistants of the AI course. Its purpose is to serve as a durable, public
record of the course's materials and the work produced around it, separate
from any single semester or any single person's involvement.

This website is the documentation front-end for that organization, built
with [MkDocs](https://www.mkdocs.org/) and the
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

## Why an archive?

Course materials tend to live in scattered places: a Moodle course that gets
reset or archived, individual student repositories, chat logs, and personal
drives. Once a semester ends, this material is easy to lose track of. The
FUM-AI-Archive organization exists to counter that by:

- Hosting a stable set of repositories per semester.
- Keeping a consistent documentation structure across semesters.
- Making historical course content easy to browse and reference.

## Relationship to the university course

This project is **not**:

- The official course website.
- A replacement for Moodle.
- A source of official announcements, deadlines, or grading information.

This project **is**:

- A community-maintained archive built by teaching assistants.
- A reference resource for students and future teaching staff.
- A historical record of how the course has evolved over time.

## Maintainers

This site and its associated repositories are maintained collaboratively by
current and former teaching assistants of the AI course. See the
[Contributing](contributing.md) page for details on how maintenance works
and how to get involved.
