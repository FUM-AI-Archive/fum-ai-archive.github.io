# Spring 2026

Welcome to the archive of the **Artificial Intelligence** course offered during the **Spring 2026** semester at **Ferdowsi University of Mashhad**.

Due to the special circumstances of the semester, all course activities were conducted **remotely**, resulting in a tutorial structure that differed from the previous semester. This section documents the organization of the course, educational materials prepared by the teaching team, repositories, assignments, projects, and other resources developed throughout the semester.

> **Note**
>
> This archive is provided for documentation and reference purposes only. During the active semester, all announcements, submissions, and grading were managed through the university's VU and the course communication group.

---

## Course Assessment

The tutorial component of the course consisted of **12 points** within the overall course assessment, with an additional **1-point programming project** provided as extra credit.

| Component                                  |               Weight |
| ------------------------------------------ | -------------------: |
| Theory Assignments (8 × 0.5)               |                  4.0 |
| Midterm I                                  |                  2.0 |
| Midterm II                                 |                  2.0 |
| Machine Learning Programming Assignments   |                  2.5 |
| Constraint Satisfaction Problems           |                  1.5 |
| **Regular Assessment Total**               |             **12.0** |
| Reinforcement Learning Programming Project | 1.0 *(Extra Credit)* |

### Theory Assignments

Eight theory assignments were released throughout the semester.

Each assignment carried **0.5 points**, for a total of **4 points**.

The assignments followed the same structure and topics as the previous semester. However, due to the remote format of the course, tutorial sessions were not held in the usual form.

Instead, **official written solutions were provided** for the theory assignments. At a designated time, students could ask questions about the assignments in the course group, where members of the teaching team and the designated person responsible for each assignment addressed questions and provided clarification.

This replaced the previous in-person format, in which assignments were discussed and solved directly during tutorial sessions and official written solutions were not published.

For the list of assignments and their topics, see the **Assignments** page.

### Midterm Examinations

The two midterm examinations were arranged around the semester schedule and the Nowruz holiday period.

* **Midterm I (2 points):** Covered the first three theory assignments.
* **Midterm II (2 points):** Covered the following four theory assignments.

The remaining material, including **Planning** and **Reinforcement Learning**, was assessed as part of the final examination.

### Machine Learning Assessment

Due to the remote format of the semester, it was not possible to conduct the Machine Learning assessment through in-person quizzes during tutorial sessions.

Instead, Machine Learning was assessed through a combination of **programming assignments and theoretical questions**.

| Assignment     |  Weight |
| -------------- | ------: |
| Perceptron     |     1.5 |
| Decision Trees |     1.0 |
| **Total**      | **2.5** |

### Programming Projects

Programming assignments were used to provide hands-on practice with several topics covered in the course.

| Project                           |                Weight |
| --------------------------------- | --------------------: |
| Machine Learning — Perceptron     |                  1.50 |
| Machine Learning — Decision Trees |                  1.00 |
| Constraint Satisfaction Problems  |                  1.50 |
| Reinforcement Learning            | 1.00 *(Extra Credit)* |

The **Reinforcement Learning** programming project was conducted in a format similar to the previous semester. Its **1-point score was provided as extra credit** and was not included in the regular 12-point assessment.
