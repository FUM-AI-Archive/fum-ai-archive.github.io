# Projects — Fall 2025

This page archives the programming projects prepared for the **Artificial Intelligence** course during the **Fall 2025** semester.

These projects were designed to reinforce the theoretical concepts covered in the course through practical implementation and analysis.

> **Note**
>
> This page documents the official course projects. Student submissions are not included in this archive.

---

## Project List

| Project | Prepared by | Description | Repository |
|---------|-------------|-------------|------------|
| **CSP Nonogram** | Mobin Teymoorpour | Students implemented a **Constraint Satisfaction Problem (CSP)** solver to solve the Nonogram puzzle using constraint propagation and search techniques. | https://github.com/TheRealMobitz/CSP_1404-1 |
| **Reinforcement Learning – Flappy Bird** | Parinaz Akef, Sania Dolat, Kian Daneshvar, Mahsa Hasanpour | A reinforcement learning project combining analytical questions with practical experimentation. ## Educational Objectives

The programming projects were designed to complement the theory assignments by providing hands-on experience with key topics in Artificial Intelligence.

Throughout the semester, students worked on projects covering:

- Constraint Satisfaction Problems (CSP)
- Reinforcement Learning
- Regression and Evolutionary Computation
